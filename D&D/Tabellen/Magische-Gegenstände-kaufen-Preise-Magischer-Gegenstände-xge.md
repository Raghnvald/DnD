# Magische Gegenstände kaufen, Preise für Magische Gegenstände
*Quelle: Xanathars Ratgeber für Alles S. 126* 

**Preise für Magische Gegenstände**

| Seltenheit   |          Verkaufspreis* |
| ------------ | -----------------------:|
| Gewöhnlich   |     `(1W6 + 1) × 10` GM |
| Ungewöhnlich |          `1W6 × 100` GM |
| Selten       |       `2W10 × 1,000` GM |
| Sehr selten  | `(1W4 + 1) × 10,000` GM |
| Legendär     |       `2W6 × 25,000` GM |
^magic-item-price

*Halbiert für Verbrauchsgegenstände wie Tränke oder Schriftrollen
