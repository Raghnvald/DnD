# Imbued Wood (Fernian Ash)
*Wondrous item, common (requires attunement)*  

Ein Ebenenholzfokus ist ein Zepter, ein Stecken oder ein Stab. Er wird aus dem Holz eines Baums geschnitzt, der von extraplanarer Energie durchdrungen ist. Als Zauberwirker kann man diese Kugel als Zauberfokus verwenden.

Verwendet man diesen Gegenstand als Zauberfokus beim Wirken eines Zaubers, der Schaden verursacht, erhält man einen Bonus von +1 auf einen Schadenswurf mit  Feuer-Zaubern.
