# Aaskriecherschleim
*Abenteuerausrüstung, Gift (Kontakt)*  

- **Eigenschaften**: [[Gegenstandseigenschaften-phb#Gifte|Gifte]]
- **Kosten**: 200 GM

Das Gift muss von einem toten oder [[Zustände-phb#Kampfunfähig|handlungsunfähigen]] [[Aaskriecher-mm|Aaskriecher]] entnommen werden. Eine Kreatur, die diesem Gift ausgesetzt wird, muss einen `Konstitutions-Rettungswurf` gegen `SG 13` schaffen, sonst ist sie 1 Minute lang [[Zustände-phb#Vergiftet|vergiftet]]. Die vergiftete Kreatur ist [[Zustände-phb#Gelähmt|gelähmt]]. Die Kreatur kann den Rettungswurf am Ende von jedem ihrer Züge wiederholen, bei einem Erfolg verschwinden die Auswirkungen des Giftes.

*Source: Dungeon Master's Guide p. 258. Available in the <span title='Systems Reference Document (5.1)'>SRD</span> (as "Crawler Mucus (Contact)")*
