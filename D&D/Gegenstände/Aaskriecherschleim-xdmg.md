# Aaskriecherschleim
*Abenteuerausrüstung, Gift (Kontakt)*  

- **Eigenschaften**: [[Gegenstandseigenschaften-xphb#Poison|Gifte]]
- **Kosten**: 200 GM

Eine Kreatur, die Kontakt mit Aaskriecherschleim hat, muss einen SG-13-Konstitutionsrettungswurf bestehen, oder sie ist eine Minute lang [[Zustände-xphb#poisoned|vergiftet]]. Solange die Kreatur auf diese Art [[Zustände-xphb#poisoned|vergiftet]] ist, ist sie außerdem [[Zustände-xphb#Paralyzed|gelähmt]]. Sie wiederholt den Rettungswurf am Ende jedes ihrer Züge. Bei einem Erfolg endet der Effekt bei ihr.

*Quelle: Spielleiterhandbuch (2024) S. 77. Verfügbar im <span title='Systems Reference Document (5.2)'>SRD</span> (als "Kriecherschleim (Kontakt)")*
